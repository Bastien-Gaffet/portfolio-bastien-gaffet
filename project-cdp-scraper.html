cdp-scraper

A command line tool that connects with the student's own credentials, walks the class documents folder on cahier-de-prepa.fr, and copies it identically to disk: same folders, same file names, private lesson schedules included.

Un outil en ligne de commande qui se connecte avec les identifiants de l'utilisateur, explore l'arborescence des documents de la classe sur cahier-de-prepa.fr, et la recopie à l'identique sur le disque : mêmes dossiers, mêmes noms de fichiers, programmes de colles compris.

Overview

Aperçu

Courses that
outlive the account. Des cours qui
survivent au compte.

cdp-scraper starts from a simple fact: documents posted on cahier-de-prepa.fr disappear the moment account access ends, at the end of the year. The tool logs in with the student's own credentials, downloads only what that account already sees, and rebuilds the exact same folder structure locally. A local viewer ships alongside it to browse lessons afterward, without a browser or a connection.

cdp-scraper part d'un constat simple : les documents déposés sur cahier-de-prepa.fr disparaissent avec l'accès au compte, une fois l'année finie. L'outil se connecte avec les identifiants de l'utilisateur, ne télécharge que ce que ce compte voit déjà, et recrée la même arborescence en local. Un visualiseur local l'accompagne pour parcourir ensuite ses cours, sans navigateur ni connexion.

How it works

Fonctionnement

01

Launch and log in

Lancer et se connecter

Run the script, enter the class URL and credentials. Password entry is masked and never stored or sent anywhere else.

Lancer le script, indiquer l'URL de la classe et les identifiants. La saisie du mot de passe est masquée et n'est jamais stockée ni transmise ailleurs.

02

The tool explores the tree

L'outil explore l'arborescence

It walks the class documents folder one request at a time, respecting the server's pace.

Il parcourt le dossier de documents de la classe une requête à la fois, au rythme du serveur.

03

Files land identically

Les fichiers arrivent à l'identique

Same folders, same names, private lesson schedules included, copied exactly as they appear online.

Mêmes dossiers, mêmes noms, programmes de colles compris, copiés exactement comme en ligne.

04

Browse them locally

Les parcourir en local

cdp_viewer.py opens a local site to read everything back: syntax highlighting for code, PDF and image previews, nothing ever leaves the machine.

cdp_viewer.py ouvre un site local pour tout relire : coloration syntaxique du code, aperçu PDF et images, rien ne quitte jamais la machine.

Stack

Stack technique
