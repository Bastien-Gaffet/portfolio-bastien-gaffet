Overview

Design that
feels good to touch.

Glacify is an ice cream ordering app built with one question in mind: what if an app actually reflected the product it was selling? Ice cream is playful, colourful, and a little indulgent. The UI had to be all of those things too, without sacrificing usability.

How it works

01

Browse the menu

Products are displayed with large visuals and clear descriptions. Filters let users find exactly what they want by flavour, size or category.

02

Customise the order

Each item can be customised: cone or cup, scoops, toppings. The interface updates the visual preview in real time.

03

Add to cart

Items are added with a satisfying animation. The cart is always visible without interrupting the browsing experience.

04

Checkout

A simple, distraction-free checkout flow. Name, pickup time, payment. Nothing unnecessary.

05

Confirmation

A friendly confirmation screen with order summary and estimated pickup time.

Stack

Mobile UIDesigned for touch-first interactions with large tap targets and smooth transitions.
UX DesignUser flows mapped and tested for minimum friction from browse to checkout.
Visual DesignCustom colour palette and typography built around the product personality.

Key concepts

Emotional design
The app uses colour, motion and micro-interactions to create a feeling, not just a function. Every screen should feel like the product.
Flow efficiency
The ordering flow is optimised to require as few taps as possible. Speed and delight are not in conflict here.
Consistency
Every component follows the same visual language. Spacing, radius, colour usage and typography are all systematic.
